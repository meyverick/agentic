## [1.0.0] - 2026-08-20

### Added

- Initial release of agentic skills for pi.dev
- skill-creator: Create new Agent Skills from problem descriptions
- opsx-learn: Analyze reports and generate OpenSpec proposals
- install.ts: One-command installation via bunx
- AGENTS.md: Agent configuration for workspace

### Skills

- **skill-creator**: Create new skills with discovery, design, authoring, validation, evaluation, optimization
- **opsx-learn**: Analyze reports, determine tools, generate OpenSpec proposals

### Prompts

- **opsx-report**: Generate self-reflection on archived changes
- **opsx-learn**: Analyze reports and generate proposals

### Scripts

- **install.ts**: Install agentic into projects via `bunx github:meyverick/agentic`
